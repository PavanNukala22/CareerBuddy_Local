{% comment %} Country-code phone input widget: a flag/dial-code picker + local-number input that keeps a Django-bound hidden field (forms.CharField with widget=forms.HiddenInput()) in sync as "+" for the server-side validator (users/forms.py: validate_international_mobile) to check with the `phonenumbers` library. Self-contained (no Bootstrap dropdown JS dependency) so it behaves the same regardless of what else is loaded on the page — see includes/language_dropdown.html for the same reasoning. Requires, once per page (not once per widget): Usage — must appear right after the matching hidden Django field so the widget can find and sync it by id ("id_", Django's default): {{ form.mobile }} {% include 'includes/phone_input.html' with field_name='mobile' placeholder='Mobile Number' %} Pass `required=True` to reject an empty value on submit ("This field is required.") — omit it (the default) for an optional field like the mobile / alternate mobile pickers, where an empty value is valid. Pass `suffix` when the SAME form is rendered more than once on one page (e.g. one modal per item in a {% for %} loop) — Django's auto id ("id_") is otherwise identical in every copy, so only the first copy's hidden field would ever get updated. Give the hidden field itself the matching id ("id__", typically the loop item's pk) and pass the same suffix here: {% include 'includes/phone_input.html' with field_name='applicant_phone' suffix=job.id placeholder='Phone Number' %} {% endcomment %}
