{% comment %} Live password requirements checklist, shared by the Job Seeker and Employer registration pages. Each rule ticks green as the user satisfies it, so all the rules stay visible instead of the user only discovering one failure at a time from a server error such as "This password is too common." The rules mirror users/password_validators.py + Django's built-in validators; the server is still the authority on acceptance.
