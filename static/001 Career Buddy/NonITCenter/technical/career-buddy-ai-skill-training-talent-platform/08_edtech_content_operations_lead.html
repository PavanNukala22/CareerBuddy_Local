    🔄 Content lifecycle governance

    Define stages and allowed transitions so unreviewed content cannot go live: draft → review → approved → published → monitored → revision or retired.

    pythonALLOWED = {"draft": ["review"], "review": ["draft", "approved"],
           "approved": ["published"], "published": ["revision", "retired"],
           "revision": ["review"]}
def move(item, new):
    if new not in ALLOWED[item.state]:
        raise ValueError("Transition not allowed")
    item.state = new

    🎲 Dynamic quiz creation

    A blueprint sets rules (tag, level, count). The generator draws only published items and avoids repeats.

    pythondef build_quiz(bank, blueprint, used):
    quiz = []
    for r in blueprint:
        pool = [q for q in bank if r["tag"] in q.tags and q.level == r["level"]
                and q.status == "published" and q.id not in used]
        quiz += random.sample(pool, r["count"])
    return quiz

    Advanced Operations and Real-World Practice

    Scale, change and govern with confidence.

    🚀 Advanced concepts

    • Item analysis: difficulty and discrimination expose weak questions.
    • Equivalent forms: blueprints keep dynamic quizzes fair.
    • Impact analysis: trace exam changes to content.
    • Many-to-many mapping: one item can serve several certifications.
    • Provenance: record source and review for AI-assisted drafts.

    🏗️ Real-world project

    Scenario: a platform with 3 certification tracks and 4,000 items.

    1. Audit tags and merge duplicates.
    2. Define lifecycle states and owners.
    3. Build coverage matrices for each track.
    4. Create blueprints for practice and mock exams.
    5. Report coverage, review backlog and item quality.

    ⭐ Best practices

    • Version every change with a log.
    • Keep tags controlled and owned.
    • Store owner, review date and licence on each item.
    • Never publish without approval.

    ⚠️ Errors and troubleshooting

    Error

    Hundreds of near-duplicate tags.

    Correction

    Audit, merge synonyms, assign owners and deprecate old tags.

    Error

    A quiz repeats the same questions.

    Correction

    Track used items and deepen the pool.

    Error

    Content stays live after the exam changed.

    Correction

    Impact analysis and a scheduled revision.
