    Module 01 · Foundations

    What is Graphic Production?

    Start from zero: what visual assets are, raster vs vector, and which file formats to use.

    🖼️ What is Graphic Production?

    Graphic production is the craft of creating and preparing the visual assets a product needs: illustrations, icons, banners, thumbnails, 3D renders and animated graphics — and delivering them in the right size, format and quality.

    🔴 Poor production

    Blurry PNG logos, 8 MB hero images, wrong colour mode, files named "final_final2".

    🟢 Good production

    Crisp SVG icons, optimised WebP images, consistent naming and a repeatable export process.

    🔀 Raster vs Vector

    Module 02 · Vector Illustration

    Vector Illustration

    Learn paths, Bézier curves, shape-building and a process for clean illustrations.

    ✒️ How Vectors Work

    PathA line made of anchor points joined by segments.
    Anchor pointCorner (sharp) or smooth (curved) control point.
    HandleBézier handle that controls curve direction and length.
    Fill and strokeInside colour and outline.
    Compound pathSeveral paths combined (a donut with a hole).
    💡
    Use as few anchor points as possible. Put points at extremes (top, bottom, left, right) of curves for clean shapes.

    Module 03 · Digital Asset Rendering

    Digital Asset Rendering and Export

    Prepare assets for screens: sizes, density, compression, colour and accessibility.

    📱 Screen Densities and Sizes

    PlatformScaleExample for 24px icon
    Web / Android mdpi1×24 × 24
    Retina / iOS @2x2×48 × 48
    iOS @3x3×72 × 72
    Android xxhdpi3×72 × 72

    Prefer SVG for icons to avoid multiple sizes; use srcset for responsive raster images.

    📦 Optimising Images

    • Resize to the maximum displayed size (e.g. hero 1600px wide).
    • Use WebP/AVIF with JPG fallback; quality 70–80 is usually enough.
    • Compress SVG with SVGO; remove metadata and hidden layers.
    • Target budgets: icon < 2 KB, thumbnail < 50 KB, hero < 200 KB.
    • Lazy-load images below the fold.
    EXAMPLE · Hero image

    Original 6 MB PNG 5000px → resized 1600px, exported WebP at 75% = 120 KB. Page loads faster and Core Web Vitals improve.

    🎨 Colour Management

    sRGBDefault web colour space; export in sRGB.
    Display P3Wider gamut for modern screens; use with sRGB fallback.
    Colour profileEmbedded definition of how colours should appear.
    Bit depth8-bit per channel is standard for web.
    📌
    Convert to CMYK only for print deliverables (certificates, brochures) and soft-proof first.

    ♿ Accessibility of Graphics

    • Add meaningful alt text; decorative images use empty alt.
    • Ensure text on images has overlay or enough contrast.
    • Avoid text baked into images; use live text.
    • Provide captions or transcripts for videos.

    📖 3D Key Terms

    PrimitiveBasic shape: cube, sphere, cylinder.
    Subdivision surfaceSmooths a low-poly mesh.

    EXAMPLE · Simple icon in 3D
    1. Add a rounded cube; bevel edges.
    2. Assign a matte brand-blue material (roughness 0.5).
    3. Light with a soft area light and HDRI.
    4. Camera at 35° with 50 mm lens.
    5. Render in Eevee with transparent background, export PNG.

    📦 Scenario

    Launch of a "Data Analytics" course. You need: a hero illustration, 12 module icons, a 3D thumbnail and a 1-minute animated intro, all on-brand and fast loading.

    1️⃣ Task 1 · Format choices

    ✍️ Choose formats for hero, icons, thumbnail and animation, and say why.
    Model answer: Hero: SVG (or WebP if textured). Icons: SVG for scalability and tiny size. Thumbnail: WebP 1280×720 with JPG fallback. Animation: Lottie for UI loops; MP4/WebM for the intro video with captions.

    2️⃣ Task 2 · Optimisation

    Q. Hero PNG is 5 MB. Best fix?
    • A Resize to display size and export WebP at about 75% quality
    • B Convert to BMP
    • C Leave it
    • D Add more detail

    3️⃣ Task 3 · 3D

    ✍️ List the steps to render the 3D thumbnail in Blender.
    Model answer: Model simple shapes → add brand-colour PBR materials → light with key/fill/rim or HDRI → set camera → render with Eevee/Cycles with denoise → export PNG/WebP → compress.

    ✍️ Describe your folder structure and naming for these assets.
    Model answer: /source (AI, BLEND) /exports/web /exports/@2x /brand. Names: icon_module-data-cleaning_24.svg, thumb_data-analytics_1280x720_v02.webp.

    Interview Preparation

    🖼️ Fundamentals

    Raster vs vector?
    Raster uses pixels and blurs when scaled (photos). Vector uses mathematical paths and scales infinitely (logos, icons).
    How do you choose between PNG, JPG, WebP and SVG?
    JPG/WebP for photos, PNG for lossless/transparent graphics, WebP/AVIF for smaller web delivery and SVG for icons and logos.
    RGB vs CMYK?
    RGB for screens (additive), CMYK for print (subtractive); convert only for print and soft-proof.

    🧊 3D and Tools

    Why use 3D in product design?
    Depth and polish for hero, product mockups and motion; faster iteration of angles and lighting than photography.
    Blender vs Cinema 4D?
    Blender: free and all-round with Eevee/Cycles. Cinema 4D: paid, strong for motion graphics and easy learning.
    How do you light a 3D object?
    Three-point lighting: key, fill, rim; add HDRI for realistic ambience.

    ⚙️ Pipeline

    How do you keep assets organised?
    Consistent naming, folder structure, versioning, metadata and a DAM or shared library.
    How do you speed up repeated exports?
    Presets, actions, scripts, CLI tools such as SVGO or ImageMagick and CI automation.
    How do you ensure performance?
    Resize, compress, modern formats, lazy-load and budgets per asset type.
