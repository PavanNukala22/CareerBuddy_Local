    Module 01 · Foundations

    What is Visual Craftsmanship?

    Start from zero: what visual craft means, the building blocks, and the main types of visual decisions.

    🎨 What is Visual Craftsmanship?

    Visual craftsmanship is the skill of turning a functional interface into one that looks clear, intentional and trustworthy. It covers typography, colour, icons, composition and layout hierarchy — every pixel decision that guides the eye and builds feeling.

    🔴 Without craft

    Random fonts, clashing colours, uneven spacing. Users struggle to know what matters and trust the product less.

    🟢 With craft

    One clear type scale, a purposeful palette, consistent icons and spacing. Users scan fast and feel confident.

    🧱 The Five Building Blocks

    🔤
    Typography
    Typefaces, sizes, weight, spacing — how text looks and reads.
    🌈
    Colour
    Palette, contrast, meaning and mood.
    🔣
    Iconography
    Small symbols that explain actions quickly.
    🧩
    Composition
    How elements are arranged inside a frame.
    📐
    Layout hierarchy
    Order of importance through size, position and space.

    📖 Key Terms

    Visual hierarchyThe order in which the eye reads elements; led by size, contrast and position.
    ContrastDifference between two elements (light/dark, big/small) that makes one stand out.
    AlignmentLining elements on shared edges or axes so the layout feels ordered.
    ProximityRelated items sit close together; unrelated items get more space.
    White spaceEmpty space (also negative space) that gives content room to breathe.
    RepetitionReusing styles so users learn patterns.
    GridInvisible columns and rows that structure a layout.
    PixelSmallest unit of a screen; designs are built from pixels (px).
    EXAMPLE · One screen, three levels

    A course card: title in 20px bold (level 1), instructor and duration in 14px regular (level 2), "Resume" button in brand colour (action). The eye reads title → meta → action without being told.

    Q. Which principle makes related items sit close together?
    • A Contrast
    • B Rhythm
    • C Repetition
    • D Proximity

    🔤 Type Basics and Classification

    Type familyLookBest forExample

    📏 Building a Type Scale

    A type scale is a fixed set of sizes that grow by a ratio, so hierarchy feels harmonious. Pick a base (16px) and a ratio (1.25 "major third").

    LevelCalculationSizeUse
    Caption16 ÷ 1.2513pxLabels, helper text
    Bodybase16pxParagraphs
    H316 × 1.2520pxCard titles
    H220 × 1.2525pxSection titles
    H125 × 1.25 × 1.2539pxPage titles
    💡
    Use one or two families only. Create contrast with size and weight, not with extra fonts.

    ♿ Contrast and Accessibility

    WCAG sets minimum contrast ratios: 4.5:1 for normal text, 3:1 for large text (24px or 19px bold) and UI components. Never use colour alone to carry meaning — add icon or text.

    EXAMPLE · Failing vs passing

    Light grey #A0A0A0 text on white is about 2.6:1 (fails). Dark grey #595959 on white is about 7:1 (passes).

    Module 03 · Iconography & Composition

    Iconography and Composition

    Design consistent icon sets and compose frames using proven rules.

    🔣 What is Iconography? Types of Icons

    TypeDescriptionUse
    Outline / lineStroke only, 1.5–2pxModern UI, navigation
    Solid / filledFilled shapesActive states, small sizes
    DuotoneTwo tonesFeature highlights
    IllustrativeDetailed, colouredOnboarding, empty states
    Logo / brand marksIdentity symbolsBrand placement
    📌
    Icons are not a replacement for labels except for universal ones (search, close, home). Pair with text when meaning is uncertain.

    📐 Designing an Icon Set

    • Build on a grid — common sizes 16, 20, 24, 32 px with a 2px safe padding (keyline shapes: circle, square, portrait, landscape).
    • Keep stroke weight identical (e.g. 1.75px) and corner radius identical across the set.
    • Use the same metaphor level — don't mix realistic and abstract.
    • Align to the pixel grid so small sizes stay crisp; export as SVG.
    • Test at the smallest size and in dark mode.

    🔴 Inconsistent set

    Mixed stroke widths, a filled icon next to outline ones, different optical sizes.

    🟢 Consistent set

    One stroke, one radius, same keyline, same visual weight.

    🧩 Composition Rules

    ➗
    Rule of thirds
    Divide a frame into a 3×3 grid; place focal points on intersections.
    🌀
    Golden ratio
    Proportion ≈ 1:1.618 for pleasing splits of space.
    ⚖️
    Balance
    Symmetric (formal) or asymmetric (dynamic) weight distribution.
    👁️
    Focal point
    One dominant element; everything else supports it.
    Gestalt: ClosureMind completes incomplete shapes.
    Gestalt: SimilaritySimilar looking items are seen as a group.
    Gestalt: Common regionItems in a shared box are grouped.
    RhythmRepeated spacing/pattern that guides movement.
    Q. Which element sets the focal point of a composition?
    • A The smallest text
    • B One dominant element with the strongest contrast
    • C The footer
    • D The most equal-weight items

    Layout, Grids and Hierarchy

    Structure whole screens with grids, spacing systems and reading patterns.

    🧭 How People Scan

    PatternWhen it happensDesign response
    F-patternText-heavy pagesPut key info on the left and in first lines
    Z-patternSparse landing pagesLogo top-left, CTA bottom-right
    Layer-cakePages with strong headingsClear, scannable headings
    GutenbergEvenly distributed contentPrimary start top-left, terminal bottom-right

    🔲 Grids and Spacing Systems

    Column gridDesktop 12 columns, tablet 8, mobile 4; gutters 16–24px.
    MarginOuter space around the grid.
    8-point systemAll spacing in multiples of 8 (4 for fine tuning): 4, 8, 16, 24, 32, 48.
    Baseline gridText sits on a 4/8px rhythm so lines align across columns.
    BreakpointsCommon: 360, 768, 1024, 1280 px.
    EXAMPLE · LMS course page

    Left 8 columns: video and lesson text. Right 4 columns: syllabus and progress. Mobile stacks to a single column with the syllabus as a collapsible section. Section spacing 48, card padding 24, item gap 16.

    Module 05 · Expert Craft

    Expert-Level Craft

    Optical adjustments, systems thinking, motion and critique that separate polished work from good work.

    🔍 Optical Refinement

    • Optical alignment: circles and triangles overshoot baselines slightly to look aligned.
    • Optical centring: play icon inside a circle is nudged right to look centred.
    • Weight balancing: icon next to text may need a 1px stroke change to match text weight.
    • Nested radius: inner radius = outer radius − padding for concentric corners.
    • Variable fonts: fine-tune weight, width and optical size on one file.

    🏗️ Design Tokens and Systems

    Primitive tokenRaw value: blue-900 = #14213D.
    Semantic tokenMeaning: color-action-primary = blue-900.
    Component tokenScoped: button-bg = color-action-primary.
    Dark modeRemap semantic tokens, don't invert colours; lower saturation and elevation by lightness.
    ✅
    Tokens let one change (brand colour) ripple safely across hundreds of components and platforms (web, iOS, Android).

    🎬 Motion and Micro-interactions

    PrincipleGuideline
    Duration150–300 ms for UI; up to 500 ms for large transitions
    EasingEase-out for entering, ease-in for leaving
    PurposeShow cause-effect, guide attention, confirm action
    AccessibilityRespect prefers-reduced-motion

    🗣️ Design Critique

    • State the goal first, then critique against it ("Does this help learners find Resume?").
    • Use "I notice… I wonder…" instead of "I like/dislike".
    • Separate issues into hierarchy, clarity, consistency, polish.
    • Document decisions so craft knowledge scales.
    Q. Why use semantic tokens?
    • A To attach meaning so values can change safely across themes
    • B To save file size
    • C To avoid using colours
    • D To replace typography

    📚 Scenario

    An LMS course card looks cluttered: three fonts, 12 colours, uneven padding, tiny grey text and no clear action. Your job is to refine it.

    1️⃣ Task 1 · Type scale

    ✍️ Define a type scale (base 16px) for the card: title, meta, button.
    Model answer: Title 20px/600, line-height 1.3; meta 14px/400, line-height 1.5 in #595959; button 14px/600. One family (Noto Sans), two weights.

    2️⃣ Task 2 · Colour

    Q. Meta text #A0A0A0 on white fails. Best fix?
    • A Make it lighter
    • B Add shadow
    • C Make it smaller
    • D Darken to at least 4.5:1 (e.g. #595959)
    ✍️ Propose a 5-colour palette and name each role.
    Model answer: Primary navy #14213D (brand/button), accent orange #D9730D (highlights), success green #0F7B0F (completed), surface #F7F6F3, text #37352F. Check all pairs ≥ 4.5:1.

    3️⃣ Task 3 · Hierarchy

    ✍️ List the order of importance on the card and how you will show it.
    Model answer: 1) Course title — largest, boldest. 2) Progress — bar with brand colour. 3) Resume button — filled primary. 4) Meta (duration, level) — small, muted. Spacing in 8-point steps: padding 24, gap 16.

    Module 07 · Interview Preparation

    Interview Preparation

    Click a question to reveal a model answer.

    🔤 Fundamentals

    What is visual hierarchy and how do you create it?
    The order the eye reads content. I create it with size, weight, colour, contrast, spacing and position, then validate with the squint test.
    How do you pick a type scale?
    Base 16px, a ratio such as 1.25, limit to 5–6 sizes, one or two families, and check line height and measure (45–75 characters).
    How do you ensure colour accessibility?
    Test contrast (4.5:1 text, 3:1 large text/UI), never rely on colour alone, and check colour-blind simulations.

    🏗️ Systems and Process

    What is an 8-point grid?
    A spacing system where all sizes and gaps are multiples of 8 (4 for small tweaks) which keeps rhythm consistent and speeds dev handoff.
    What are design tokens?
    Named values (colour, type, spacing) in layers — primitive, semantic, component — that sync design and code and enable theming.
    How do you handle dark mode?
    Remap semantic tokens with reduced saturation, check contrast again, use lighter surfaces for elevation instead of shadows.

    🗣️ Critique

    A stakeholder says "make the logo bigger". What do you do?
    Ask what problem they want solved (visibility?). Show hierarchy evidence, test alternatives and agree on the goal rather than a size.
    How do you give design feedback?
    Anchor to goals, describe observations ("I notice…"), suggest options and separate hierarchy, clarity, consistency and polish.
