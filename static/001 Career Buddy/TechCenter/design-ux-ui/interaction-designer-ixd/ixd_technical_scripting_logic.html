    Module 01 · Foundations

    Why Interaction Designers Script

    Start from zero: why logic skills help IxDs, and the basic programming vocabulary — variables, expressions, conditions, events and functions.

    🧭 What is Technical Scripting for Designers?

    Interaction designers don't need to be engineers, but basic logic and scripting lets you build realistic prototypes, write precise specs and speak the same language as front-end developers. It is listed as advantageous because it makes your designs more buildable and testable.

    🧪
    Realistic prototypes
    Counters, validation, conditional screens in ProtoPie/Framer.
    🎬
    Smarter motion
    After Effects expressions instead of hundreds of keyframes.
    🤝
    Better handoff
    Specs written as states, variables and events.
    🔍
    Feasibility sense
    Know what is easy or hard to build.

    📖 Core Concepts (What is What)

    VariableA named container for a value: cartCount = 3.
    Data typeKind of value: number, string (text), boolean (true/false), array (list), object (group of named values).
    ExpressionA piece of code that produces a value: price * qty.
    OperatorSymbols that combine values: + − * / == != > < && ||.
    ConditionAn expression that is true or false, used in if/else.
    FunctionA reusable block of logic: formatPrice(1499).
    EventSomething that happens: click, input, scroll, timer.
    StateThe data that describes the UI right now.

    🗂️ Types of Data

    Events, Conditions & Logic Hooks

    Connect user actions to logic: event listeners, conditional branches and React hooks.

    ⚡ Events & Listeners

    Interactive code follows event → logic → update. An event listener waits for an event and runs a function (a "handler").

    javascriptbutton.addEventListener("click", () => {
  if (!isSubmitting) {
    isSubmitting = true;
    showSpinner();
    submitForm();
  }
});
    Event typeExamples
    Pointerclick, pointerdown, pointerup, hover (pointerenter)
    Keyboardkeydown (Enter, Escape)
    Forminput, change, focus, blur, submit
    Scroll / viewscroll, IntersectionObserver (element visible)
    TimesetTimeout, setInterval
    Systemonline / offline, visibilitychange

    🔀 Conditional Branching

    javascriptfunction getDeliveryMessage(hour, pincodeServiceable) {
  if (!pincodeServiceable) return "We don't deliver here yet";
  if (hour >= 21) return "Delivery tomorrow morning";
  return "Delivery in 30 minutes";
}
    💡
    Early returns ("guard clauses") keep logic readable — the same idea as guards in a state machine.

    🪝 What are Hooks?

    In React, hooks are functions that let components "hook into" state and lifecycle. Designers meet them in Framer code components and in developer conversations.

    HookPurposeDesign meaning
    useStateStore a value that changes the UI"This toggle remembers on/off"
    useEffectRun side effects after render (fetch, timers)"When the screen opens, load orders"
    useRefKeep a value/element without re-rendering"Focus this input on open"
    useMemoCache an expensive calculation"Filter 5,000 items only when filters change"
    Custom hooksReusable logic, e.g. useDebounce"Search waits 300 ms after typing"

    Module 04 · Front-end State

    Front-End State Management Concepts

    Understand where UI data lives, how it flows, and why it matters for interaction design.

    🗄️ What is State Management?

    State management is how a front-end app stores, updates and shares the data that drives the UI. When state is in the wrong place, users see bugs like a cart badge that doesn't update or a filter that resets.

    🗂️ Types of State

    TypeLives inExample
    Local / component stateOne componentDropdown open/closed
    Shared / lifted stateNearest common parentSelected tab affects header and content
    Global / app stateStore or contextLogged-in user, cart, theme
    Server stateBackend, cached on clientOrders list, product data
    URL stateAddress bar / routeSearch query, filters, page number
    Form stateForm libraryField values, touched, errors
    Persistent statelocalStorage / deviceDraft message, preferences
    💡
    Designer rule of thumb: if users expect it to survive a refresh or be shareable, put it in the URL or server (e.g. search filters).

  switch (action.type) {
    case "ADD":    return { ...state, items: [...state.items, action.item] };
    case "REMOVE": return { ...state, items: state.items.filter(i => i.id !== action.id) };
    case "CLEAR":  return { ...state, items: [] };

  }

    🎬 After Effects Expressions

    Expressions are small JavaScript snippets attached to a property (position, opacity, rotation). They generate motion procedurally instead of hand-keyframing.

    ExpressionWhat it does
    wiggle(2, 10)Random movement: 2 times/second, up to 10 px
    loopOut("cycle")Repeat keyframes forever
    time * 90Rotate 90° per second (spinner)
    linear(time, 0, 1, 0, 100)Map 0–1 s to 0–100 (remap values)
    ease(t, tMin, tMax, v1, v2)Eased interpolation
    thisComp.layer("Ctrl").effect("Slider")("Slider")Link a property to a control slider
    valueAtTime(time - 0.05)Follow another layer with a delay (stagger)

amp = 0.06; freq = 3; decay = 6;
n = 0;
if (numKeys > 0) { n = nearestKey(time).index; if (key(n).time > time) n--; }
if (n == 0) { value } else {
  t = time - key(n).time;

  value + v * amp * Math.sin(freq * t * 2 * Math.PI) / Math.exp(decay * t);
}

    Module 06 · Interview Preparation

    Interview Preparation

    Click a question to reveal a model answer.

    🔢 Variables & Logic Questions

    Why should an interaction designer know scripting?
    To build realistic prototypes with real logic, write precise specs, understand feasibility and communicate in the same terms as front-end engineers.
    What are the basic data types?
    Number, string, boolean, array, object and null/undefined. Choosing the right one matters, e.g. a toggle is a boolean and a cart is an array of objects.
    Explain the ternary operator with a UI example.
    condition ? a : b — e.g. qty === 1 ? "item" : "items" for correct pluralisation.
    How do you avoid negative or invalid values in expressions?
    Clamp them, e.g. Math.max(0, 499 − subtotal), and specify boundary values (0, 1, max) in the spec.

    🪝 Events & Hooks Questions

    What is an event listener?
    Code that waits for an event (click, input, scroll) and runs a handler function in response.
    What do useState and useEffect do?
    useState stores a value that changes what the component renders; useEffect runs side effects after render, such as fetching data or starting timers.
    Debounce vs throttle?
    Debounce runs only after the user stops for a set time (search-as-you-type). Throttle runs at most once per interval (scroll or resize handlers).
    How do you prevent a double submission in code?
    Track a status ("idle" | "submitting") and ignore SUBMIT while submitting, disabling the button — the same logic as a state machine.

    🗄️ State Management & Tool Questions

    What types of front-end state exist?
    Local, shared/lifted, global, server, URL, form and persistent state. Each lives in a different place depending on scope and lifetime.
    Where should search filters live and why?
    In the URL, so they survive refresh and back navigation and can be shared as a link.
    What is derived state?
    Values calculated from existing state rather than stored separately, like cart total from items. It can never go out of sync.
    What is a reducer?
    A pure function (state, action) → new state that handles all updates in one predictable place, used by useReducer and Redux.
    Name useful After Effects expressions.
    wiggle() for random motion, loopOut("cycle") for loops, time * n for continuous rotation, linear()/ease() for remapping values, and valueAtTime() for delayed follow-through.

    🎟️ Scenario: ShowTime Ticket Booking

    ShowTime sells movie tickets. You are prototyping the seat-selection widget: max 6 seats, price depends on row (Premium ₹350, Regular ₹200), seats can be taken by others while you choose, and a 5-minute hold timer starts after the first seat is selected.

    1️⃣ Task 1 · Variables

    ✍️ List the variables (name, type, default) needed.
    Model answer: selectedSeats: array = [], maxSeats: number = 6, holdSecondsLeft: number = 300, status: string = "browsing" ("browsing" | "holding" | "expired" | "paying"), takenSeats: array (from server), prices: object = { premium: 350, regular: 200 }.

    2️⃣ Task 2 · Expressions

    ✍️ Write expressions for total price and the button label.
    Model answer: const total = selectedSeats.reduce((s, seat) => s + prices[seat.type], 0);
    const label = selectedSeats.length === 0 ? "Select seats" : `Pay ₹${total} for ${selectedSeats.length} ${selectedSeats.length === 1 ? "seat" : "seats"}`;
    Q. Should "total" be stored as its own variable updated manually?
    • A Yes, always
    • B No — derive it from selectedSeats so it never gets out of sync
    • C Only on Mondays
    • D Store it in the URL

    3️⃣ Task 3 · Event Logic

    ✍️ Write the logic for tapping a seat.
    Model answer: if (takenSeats.includes(seat.id)) return showToast("Seat just got booked"); → if already selected, remove it; else if selectedSeats.length >= maxSeats show "Max 6 seats" with selection haptic; else add it, and if it is the first seat set status = "holding" and start the timer.

    4️⃣ Task 4 · State Machine

    Q. The hold timer reaches 0. Next state?

    • B expired — release seats, show "Your hold expired" + Start again
    • C browsing with seats still selected
    • D No change

    Model answer: { browsing: { SELECT: "holding" }, holding: { SELECT: "holding", CLEAR: "browsing", TIMEOUT: "expired", PAY: "paying" }, expired: { RESTART: "browsing" }, paying: { SUCCESS: "booked", FAIL: "holding" }, booked: {} }
