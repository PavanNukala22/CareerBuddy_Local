    Module 01 · Foundations

    Backend Languages & Runtimes

    Start from zero: what a language and a runtime are, the types that exist, and the vocabulary you need.

    🧭 What is a Backend Language & Runtime?

    The backend is the server side of an application: it receives requests, applies business rules, talks to databases and returns responses. A language is how you write that logic; a runtime is the engine that actually executes it (memory, threads, I/O).

    ⌨️
    Language
    Syntax and rules you write
    ⚙️
    Runtime
    Executes code, manages memory and threads
    📦
    Framework
    Ready-made web tooling on top
    🔧
    Package manager
    Fetches and versions libraries

    MemoryGarbage collected · ManualAll five here are garbage collected

    📖 Key Terms (What is What)

    JITJust-In-Time compiler: turns hot bytecode into machine code at runtime.
    Garbage collectorAutomatically frees memory no longer referenced.
    Blocking vs non-blockingWhether a thread waits for I/O or continues other work.
    Concurrency vs parallelismInterleaving tasks vs running them at the same instant on several cores.
    Throughput vs latencyRequests per second vs time per request.
    Cold startTime before a fresh process serves its first request.

    Module 02 · Node.js

    Node.js

    JavaScript on the server: fast I/O-heavy APIs with one event loop.

    🟢 What is Node.js?

    Node.js is a runtime that runs JavaScript outside the browser using Google's V8 engine and libuv for non-blocking I/O. It uses a single-threaded event loop, so one process can handle thousands of waiting connections.

    🗂️ Types & Ecosystem

    AreaOptions
    Module systemsCommonJS (require) · ES Modules (import)
    FrameworksExpress (minimal) · Fastify (fast) · NestJS (structured, TypeScript)
    RuntimesNode.js · Deno · Bun
    Package managernpm · pnpm · yarn

    🌱 Basic · Core Syntax & Examples

    javascriptconst http = require('http');
const items = [1, 2, 3];                 // array
const double = n => n * 2;               // arrow function
http.createServer((req, res) => {
  res.writeHead(200, {'Content-Type': 'application/json'});
  res.end(JSON.stringify(items.map(double)));
}).listen(3000);
    Try it

    Run node server.js, open localhost:3000 and see [2,4,6].

    🛠️ Intermediate · Building Services

    javascriptimport express from 'express';
const app = express(); app.use(express.json());
app.get('/users/:id', async (req, res, next) => {
  try { res.json(await db.findUser(req.params.id)); }
  catch (e) { next(e); }               // central error handler
});
app.listen(3000);

    Use async/await for I/O, validate input, and always forward errors to one error-handling middleware.

    🚀 Expert · Internals & Production

    • Event loop phases: timers → pending → poll (I/O) → check (setImmediate) → close; microtasks (promises, nextTick) run between them.
    • Never block the loop: CPU work (hashing, JSON of huge payloads) freezes all requests. Use worker_threads.
    • Scale: cluster or one process per core behind a load balancer.
    • Streams & backpressure keep memory flat for large files.
    • Diagnose: --inspect, clinic.js, event-loop-lag metrics.
    Q. Why can a CPU-heavy loop hurt a Node.js server?
    • A It blocks the single event loop, delaying every request
    • B Node cannot run loops
    • C It disables npm
    • D It closes sockets

    Module 03 · Python

    Python

    Readable, productive, and dominant in APIs, automation and data/AI backends.

    🐍 What is Python?

    Python is a high-level, dynamically typed language. The standard runtime, CPython, compiles source to bytecode and interprets it. Its clear syntax makes it very fast to build with.

    🗂️ Types & Ecosystem

    AreaOptions
    ImplementationsCPython · PyPy (JIT) · Jython
    FrameworksDjango (batteries included) · Flask (micro) · FastAPI (async, typed)
    Concurrencythreads · multiprocessing · asyncio
    Toolingvenv · pip · poetry · uv

    🌱 Basic · Core Syntax & Examples

    pythonprices = {"tea": 20, "coffee": 35}            # dict
def total(items):                              # function
    return sum(prices[i] for i in items)       # generator expr
print(total(["tea", "coffee"]))                # 55
squares = [n * n for n in range(5)]            # list comprehension
    Try it

    Add a try/except KeyError so unknown items return 0.

    🛠️ Intermediate · Building Services

    pythonfrom fastapi import FastAPI
from pydantic import BaseModel
app = FastAPI()
class Order(BaseModel):
    item: str
    qty: int = 1
@app.post("/orders")
async def create(o: Order):
    return {"item": o.item, "total": o.qty * 20}

    Type hints + Pydantic give automatic validation and OpenAPI docs. Run with uvicorn main:app.

    🚀 Expert · Internals & Production

    • GIL: only one thread runs Python bytecode at a time. Threads help I/O; use multiprocessing or worker processes for CPU.
    • asyncio: one event loop; one blocking call stalls everything. Use async drivers.
    • Production: gunicorn/uvicorn workers per core, pinned dependencies, mypy, pytest.
    • Profile: cProfile, py-spy; move hot loops to C extensions or NumPy.
    Q. What does the GIL restrict in CPython?
    • A Memory use
    • B Parallel execution of Python bytecode across threads
    • C File access
    • D Type hints

    Module 04 · Java

    Java

    Enterprise-grade, statically typed, with the mature JVM and Spring ecosystem.

    ☕ What is Java?

    Java compiles to bytecode that runs on the JVM, which JIT-compiles hot code to native speed and manages memory with a garbage collector. "Write once, run anywhere."

    🗂️ Types & Ecosystem

    TermMeaning
    JVM / JRE / JDKVirtual machine · JVM + libraries · JRE + compiler and tools
    EditionsJava SE (core) · Jakarta EE (enterprise APIs)
    FrameworksSpring Boot · Quarkus · Micronaut
    Build toolsMaven · Gradle

    🌱 Basic · Core Syntax & Examples

    javapublic record Product(String name, double price) {}
List<Product> list = List.of(new Product("Pen", 10), new Product("Book", 250));
double total = list.stream()
    .filter(p -> p.price() > 5)
    .mapToDouble(Product::price).sum();
    Try it

    Use Optional to find a product by name without returning null.

    🛠️ Intermediate · Building Services

    java@RestController
@RequestMapping("/products")
class ProductController {
  private final ProductService service;
  ProductController(ProductService s) { this.service = s; }  // DI
  @GetMapping("/{id}")
  Product get(@PathVariable long id) { return service.find(id); }
}

    Spring Boot wires beans by dependency injection, auto-configures the server and exposes metrics via Actuator.

    🚀 Expert · Internals & Production

    • GC choice: G1 (default), ZGC/Shenandoah (very low pause). Tune heap with -Xms/-Xmx.
    • JIT tiers: warm-up matters; benchmark with JMH, not a single run.
    • Virtual threads (Java 21): cheap threads that make blocking-style code scale.
    • Diagnose: JFR, jstack, heap dumps; watch for memory leaks via static collections.
    Q. Which tool compiles Java source, JDK or JRE?
    • A JRE
    • B JDK
    • C Neither
    • D Both equally

    Module 05 · Go

    Go

    Simple, compiled, and built for concurrent network services.

    🐹 What is Go?

    Go (Golang) compiles to a single static native binary with a small runtime (scheduler + garbage collector). Its design goals are simplicity, fast builds and easy concurrency with goroutines.

    🗂️ Types & Ecosystem

    ConceptMeaning
    GoroutineLightweight thread managed by the Go scheduler
    ChannelTyped pipe to pass data between goroutines
    FrameworksStandard net/http · Gin · Echo · Chi
    Modulesgo.mod manages dependencies

    🌱 Basic · Core Syntax & Examples

    gotype User struct { Name string; Age int }
func find(id int, m map[int]User) (User, error) {
    u, ok := m[id]
    if !ok { return User{}, fmt.Errorf("user %d not found", id) }
    return u, nil          // errors are values, not exceptions
}
    Try it

    Return a sentinel error and compare it with errors.Is.

    🛠️ Intermediate · Building Services

    gofunc main() {
    http.HandleFunc("/hello", func(w http.ResponseWriter, r *http.Request) {
        fmt.Fprintln(w, "hello")
    })
    var wg sync.WaitGroup
    for i := 0; i < 3; i++ {
        wg.Add(1)
        go func(n int) { defer wg.Done(); work(n) }(i)
    }
    wg.Wait()
    http.ListenAndServe(":8080", nil)
}

    Pass a context.Context to every request-scoped call for timeouts and cancellation.

    🚀 Expert · Internals & Production

    • Scheduler (G-M-P): goroutines multiplexed over OS threads; blocking syscalls hand off the thread.
    • Races: run go test -race; protect shared state with sync.Mutex or channels.
    • Leaks: a goroutine blocked forever never exits. Always have a cancel path.
    • Profile: pprof, escape analysis (-gcflags=-m); tiny Docker images from static binaries.
    Q. How does Go idiomatically report errors?
    • A Exceptions
    • B A returned error value
    • C Global flags
    • D Panics only

    Module 06 · C# (.NET)

    C# (.NET)

    Modern, strongly typed, high-performance language of the .NET platform.

    🔷 What is C# (.NET)?

    C# compiles to Intermediate Language (IL) that the .NET runtime (CLR) JIT-compiles. It combines strong typing, rich async support and the cross-platform ASP.NET Core web framework.

    🗂️ Types & Ecosystem

    TermMeaning
    .NET FrameworkLegacy, Windows-only
    .NET (5+)Modern, cross-platform, open source
    WebASP.NET Core: minimal APIs · MVC controllers
    Data / ToolingEF Core · Dapper · NuGet · dotnet CLI

    🌱 Basic · Core Syntax & Examples

    csharprecord Product(string Name, decimal Price);
var items = new List<Product> { new("Pen", 10), new("Book", 250) };
var costly = items.Where(p => p.Price > 100)       // LINQ
                  .Select(p => p.Name).ToList();

    csharpvar builder = WebApplication.CreateBuilder(args);
builder.Services.AddScoped<IProductService, ProductService>(); // DI

    await s.FindAsync(id) is { } p ? Results.Ok(p) : Results.NotFound());

    Always await async calls and accept a CancellationToken.

    🚀 Expert · Internals & Production

    • GC generations: gen0/1/2 and the large object heap; avoid allocating in hot paths.
    • Span<T> / Memory<T>: slice data without copying.
    • Native AOT: ahead-of-time compile for fast startup and small footprint.
    • Pitfalls: .Result/.Wait() can deadlock; use Channel<T> for producer/consumer; measure with BenchmarkDotNet and dotnet-trace.

    Practice: Choose, Build and Tune

    Apply everything to a realistic scenario and justify each decision.

    🛒 Scenario: QuickCart Order API

    0 / 0 correct

    QuickCart needs an order API: 5,000 requests/second, mostly database and payment-gateway calls (I/O), plus a small image-resizing job (CPU).

    1️⃣ Task 1 · Pick a Runtime

    Q. Which runtime fits the I/O-heavy API best with the least tuning?
    • A Python with threads only
    • B Go or Node.js
    • C Any, with a CPU-bound design
    • D None
    ✍️ Choose a language for the API and a different one for the image job. Justify both.
    Model answer: API: Go (goroutines, low memory, single binary). Image job: Python workers with Pillow/NumPy or Go worker pool, scaled via a queue, so CPU work never blocks the API.

    2️⃣ Task 2 · Fix the Bottleneck

    ✍️ A Node.js endpoint hashes large payloads synchronously and latency spikes. What do you change?
    Model answer: Move hashing to worker_threads (or a separate service), measure event-loop lag, add timeouts and rate limits.

    3️⃣ Task 3 · Production Readiness

    ✍️ List five checks before launching the service in any language.
    Model answer: Health endpoints, structured logs, metrics and tracing, graceful shutdown, timeouts and retries, dependency pinning, load test with a p95/p99 target.
