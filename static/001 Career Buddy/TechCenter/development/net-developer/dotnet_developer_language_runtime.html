    🧭 What is C# and .NET?

    C# (C-sharp) is a modern, type-safe, object-oriented programming language created by Microsoft. .NET is the platform (runtime + libraries + tools) that runs it. You write C# → the compiler produces IL → the .NET runtime (CLR) executes it.

    🌐
    Web
    ASP.NET Core APIs, MVC, Blazor.
    🖥️
    Desktop & Mobile
    WPF, WinForms, .NET MAUI.
    ☁️
    Cloud & Services
    Microservices, Azure Functions, workers.
    🎮
    Games & IoT
    Unity (C#), IoT and AI/ML workloads.
    💡
    Mental model: C# = the language you write · .NET = the platform that runs and supports it · CLR = the engine inside .NET that executes your compiled code.

    🏗️ Classes and Objects

    A class is a blueprint; an object is an instance. Members: fields, properties, methods, constructors, events.

    C#public class Account
{
    public string Owner { get; }                 // read-only property
    public decimal Balance { get; private set; } // private setter
    public Account(string owner) => Owner = owner;
    public void Deposit(decimal amt)
    {
        if (amt <= 0) throw new ArgumentOutOfRangeException(nameof(amt));
        Balance += amt;
    }
}
    ModifierVisible to
    publicEveryone
    privateSame class only (default for members)
    protectedClass and derived classes
    internalSame assembly (default for types)
    private protected / protected internalCombinations of the above

    🧪 Generics, Delegates, Events & Lambdas

    C#public class Repo<T> where T : class, new()      // generic with constraints
{
    private readonly List<T> _items = new();
    public void Add(T item) => _items.Add(item);
}
Func<int, int, int> add = (a, b) => a + b;       // delegate + lambda
Action<string> log = Console.WriteLine;
public event EventHandler<string>? Saved;        // event = restricted delegate

    Func<> returns a value, Action<> returns void, Predicate<T> returns bool. Generics give type safety without boxing.

    🎯 Pattern Matching & Nullable Reference Types

    C#string Describe(object o) => o switch
{
    int n when n < 0          => "negative int",
    int                       => "int",
    string { Length: 0 }      => "empty string",
    Person { Age: >= 18 } p   => $"adult {p.Name}",
    [1, 2, ..]                => "list starting 1,2",    // list pattern
    null                      => "null",
    _                         => "other"
};

    Nullable reference types (<Nullable>enable</Nullable>) make the compiler warn when a possibly-null value is dereferenced: string = never null, string? = may be null. Treat these warnings as errors in new projects.

    ⏳ Async / Await & Tasks

    What: asynchronous code frees a thread while waiting for I/O (DB, HTTP, file). Task / Task<T> represent the work; the compiler turns async methods into a state machine.

    C#public async Task<string> GetAsync(HttpClient http, CancellationToken ct)
{
    var res = await http.GetAsync("https://example.com", ct);
    return await res.Content.ReadAsStringAsync(ct);
}
var results = await Task.WhenAll(GetAsync(h, ct), GetAsync(h, ct));  // parallel I/O
await foreach (var row in StreamRowsAsync()) { }                      // IAsyncEnumerable<T>
    • Never block with .Result / .Wait() (deadlocks, thread starvation).
    • Prefer async Task over async void (only for event handlers).
    • Pass a CancellationToken through every layer.
    • Use ValueTask only for hot paths that often complete synchronously.

    🧭 What is .NET? Framework vs Core vs .NET 5+

    .NET is a free, open-source, cross-platform developer platform: runtime + base class library (BCL) + SDK + compilers. It has evolved through three eras:

    .NET Framework.NET Core (1.0–3.1).NET 5 → 8 → 9 → 10
    PlatformWindows onlyWindows, Linux, macOSWindows, Linux, macOS (+ mobile, WASM)
    StatusMaintenance (4.8.x), legacy appsEnded — replacedCurrent, unified platform
    DeployMachine-wide installSide-by-side, self-containedSide-by-side, self-contained, NativeAOT
    Use forMaintaining old appsMigrate awayAll new development
    📝
    "Core" was dropped from the name in .NET 5. Even-numbered releases are LTS (3 years): .NET 8 and .NET 10. Odd releases like .NET 9 are STS. Always confirm end-of-support dates on Microsoft's lifecycle page.

    ⚙️ What is the CLR?

    The Common Language Runtime is the execution engine of .NET. It loads assemblies, compiles IL to machine code, manages memory, enforces type safety and security boundaries, and schedules threads. Code that runs under it is called managed code.

    🔄
    JIT compiler
    IL → native code at run time.
    🗑️
    Garbage collector
    Automatic memory reclamation.
    🧱
    Type system (CTS)
    Common types shared by all .NET languages.
    🔐
    Loader & verification
    Loads assemblies, checks metadata and types.

    🛤️ Compilation Pipeline

    StepWhat happens
    1. CompileRoslyn compiles C# → IL + metadata inside an assembly (.dll / .exe)
    2. LoadCLR loads the assembly via AssemblyLoadContext
    3. JITMethods are compiled to native code on first call (tiered compilation: quick Tier-0, then optimised Tier-1 for hot methods; PGO improves it)
    4. ExecuteNative code runs; GC and thread pool serve it
    AlternativesReadyToRun (precompiled startup code), NativeAOT (fully native, no JIT)
    C#// Inspect your own assembly at run time (reflection)
var asm = typeof(Program).Assembly;
Console.WriteLine(asm.GetName().Version);
foreach (var t in asm.GetTypes().Take(3)) Console.WriteLine(t.FullName);

    Terms: IL (CIL/MSIL) is CPU-independent bytecode · CTS defines types · CLS is the subset all languages can consume · BCL is the base library.

    🧠 Memory: Stack, Heap and Garbage Collection

    AreaHoldsCleanup
    StackLocal value types, method frames, referencesAutomatic on method return
    Managed heapReference-type objectsGarbage collector
    LOH (Large Object Heap)Objects ≥ ~85,000 bytesCollected with Gen 2 (costly)

    The GC is generational: new objects start in Gen 0; survivors move to Gen 1 then Gen 2. Most objects die young, so Gen 0 collections are cheap. Modes: workstation vs server, concurrent/background GC.

    C#public sealed class FileLogger : IDisposable
{
    private readonly StreamWriter _w = new("log.txt");
    public void Dispose() { _w.Dispose(); GC.SuppressFinalize(this); }
}
using var log = new FileLogger();        // deterministic cleanup of unmanaged resources
Console.WriteLine(GC.CollectionCount(0)); // Gen-0 collections so far
    ⚠️
    The GC frees memory, not unmanaged resources (files, sockets, DB connections). Implement IDisposable and use using. Avoid calling GC.Collect() manually. Beware leaks from static references, event handlers never unsubscribed, and captured closures.

    🧵 Threads, ThreadPool & Diagnostics

    • ThreadPool runs Tasks; async I/O does not occupy a thread while waiting.
    • Synchronise shared data with lock (Lock type in .NET 9), Interlocked, ConcurrentDictionary, Channel<T>.
    • Tools: dotnet-counters, dotnet-trace, dotnet-dump, Visual Studio profiler, PerfView, BenchmarkDotNet.

    You are building BookShelf, a small ASP.NET Core Web API on .NET 8 that stores books and returns them to a front-end.

    3️⃣ Task 3 · Async & DI

    ✍️ Create a minimal API endpoint GET /books/{id} using an injected IBookService; return 404 if missing. Which lifetime for a service using EF Core DbContext?
    Model answer: 
    C#app.MapGet("/books/{id:int}", async (int id, IBookService s, CancellationToken ct) =>
    await s.FindAsync(id, ct) is { } b ? Results.Ok(b) : Results.NotFound());
    Lifetime: Scoped (DbContext is per-request, not thread-safe).

    4️⃣ Task 4 · CLR Reasoning

    ✍️ Latency spikes appear under load and GC.CollectionCount(2) climbs rapidly. List 3 likely causes and fixes.
    Model answer: 1) Large (>85 KB) buffers hitting the LOH → use ArrayPool<T>/streaming. 2) Excess allocations in hot paths (boxing, string concat, LINQ in loops) → Span<T>, StringBuilder, structs. 3) Leaks (static caches, unsubscribed events) → bound caches, unsubscribe, IDisposable. Measure first with dotnet-counters and BenchmarkDotNet.
