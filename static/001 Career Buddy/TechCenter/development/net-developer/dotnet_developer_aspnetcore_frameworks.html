    Module 01 · Foundations

    ASP.NET Core Foundations

    What is what: the platform, the four frameworks and the concepts they share.

    🧭 What is .NET and ASP.NET Core?

    .NET is Microsoft's free, open-source, cross-platform developer platform (runtime + libraries + C# language + tooling). ASP.NET Core is the part of .NET used to build web applications and services. It runs on Windows, Linux and macOS and uses the built-in Kestrel web server.

    🔌
    Web API
    Controller-based HTTP services that return JSON for apps and SPAs.
    🧱
    MVC
    Server-rendered web pages using Model–View–Controller.
    ⚡
    Minimal APIs
    Lightweight endpoints in a few lines, no controllers.
    🧩
    Blazor
    Interactive web UI written in C# instead of JavaScript.
    💡
    All four frameworks share the same foundation: Program.cs, middleware pipeline, dependency injection, configuration and routing. Learn these once and every framework gets easier.

    🗂️ Types at a glance

    FrameworkWhat it isOutputBest for
    Web APIControllers + attributes for HTTP servicesJSON / XMLMobile & SPA backends, large teams
    MVCControllers + Razor viewsHTML pagesSEO-friendly, server-rendered sites
    Minimal APIsLambda-based endpoint mappingJSONMicroservices, small & fast APIs
    BlazorRazor components in C#Interactive UIFull-stack C# teams, internal apps

    ⚙️ Shared building blocks

    KestrelCross-platform web server that listens for HTTP requests.
    MiddlewareComponents in a pipeline; each can handle the request or pass it on (logging, auth, routing).
    Dependency InjectionBuilt-in container that supplies services (Singleton, Scoped, Transient lifetimes).
    Configurationappsettings.json, environment variables, user-secrets, Options pattern.
    RoutingMaps a URL + HTTP verb to code that handles it.
    Model bindingConverts route, query, header and body data into C# parameters.

    NeedChoose
    JSON API consumed by React/Angular/mobileWeb API (or Minimal APIs)
    Public marketing site that needs SEOMVC or Razor Pages
    Tiny microservice, best startup timeMinimal APIs
    Rich interactive UI, team knows C#Blazor
    📝

    Module 02 · ASP.NET Core Web API

    ASP.NET Core Web API

    From REST basics and your first controller to JWT security, error handling and production patterns.

    🔌 Basic · What is a Web API?

    A Web API exposes data and actions over HTTP so other programs can use them. ASP.NET Core Web APIs usually follow REST: resources identified by URLs and manipulated with HTTP verbs.

    VerbActionExampleSuccess code
    GETReadGET /api/books/5200
    POSTCreatePOST /api/books201
    PUT / PATCHReplace / partial updatePUT /api/books/5200 / 204
    DELETERemoveDELETE /api/books/5204

    Common status codes: 400 bad request, 401 unauthenticated, 403 forbidden, 404 not found, 409 conflict, 500 server error.

    🗂️ Basic · Types of controller return values

    Return typeUse
    IActionResultAny response; flexible but untyped
    ActionResult<T>Typed body or an error result; best for OpenAPI docs
    Task<ActionResult<T>>Async version (recommended for I/O)
    Plain type TAlways 200 OK

    🧪 Basic · Your first controller

    csharp[ApiController]
[Route("api/[controller]")]
public class BooksController : ControllerBase
{
    private readonly IBookService _svc;
    public BooksController(IBookService svc) => _svc = svc;

    [HttpGet]
    public async Task<ActionResult<List<Book>>> GetAll() => await _svc.GetAllAsync();

    [HttpGet("{id:int}")]
    public async Task<ActionResult<Book>> Get(int id)
    {
        var book = await _svc.GetAsync(id);
        return book is null ? NotFound() : book;
    }

    [HttpPost]
    public async Task<ActionResult<Book>> Create(CreateBookDto dto)
    {
        var book = await _svc.CreateAsync(dto);
        return CreatedAtAction(nameof(Get), new { id = book.Id }, book);
    }
}
    💡
    [ApiController] adds automatic 400 responses for invalid models, binding-source inference and ProblemDetails errors.

    🚀 Expert · Security, resilience, performance

    csharp// JWT bearer authentication + policy-based authorization

    .AddJwtBearer(o => o.TokenValidationParameters = new()
    {

// Global exception handling (.NET 8+)
public class GlobalHandler : IExceptionHandler
{
    public async ValueTask<bool> TryHandleAsync(HttpContext ctx, Exception ex, CancellationToken ct)
    {
        ctx.Response.StatusCode = 500;
        await ctx.Response.WriteAsJsonAsync(new ProblemDetails { Title = "Unexpected error" }, ct);
        return true;
    }
}
builder.Services.AddExceptionHandler<GlobalHandler>();
    • Rate limiting (AddRateLimiter), output caching, response compression, health checks.
    • Action filters for cross-cutting logic (audit, validation).
    • Observability: structured logging (Serilog), OpenTelemetry traces and metrics.
    • Testing: unit tests with xUnit + Moq; integration tests with WebApplicationFactory.
    • Architecture: Clean Architecture, CQRS (MediatR), Outbox pattern, idempotent POSTs.
    ⚠️
    Keep secrets (JWT key, connection strings) in user-secrets or a vault, never in source control.

    Module 03 · ASP.NET Core MVC

    ASP.NET Core MVC

    Server-rendered web apps: the pattern, routing, Razor views, forms, filters and security.

    🧱 Basic · What is MVC?

    MVC splits a web app into three parts so each has one job.

    🗃️
    Model
    Data and business rules (classes, EF Core entities).
    🖼️
    View
    Razor (.cshtml) templates that produce HTML.
    🎛️
    Controller
    Receives the request, calls the model, picks the view.

    Flow: Browser → Routing → Controller action → Model → View → HTML response.

    🗂️ Basic · Types & key pieces

    PieceMeaning
    Conventional routing{controller=Home}/{action=Index}/{id?} pattern in Program.cs
    Attribute routing[Route], [HttpGet] on actions
    Razor PagesPage-focused alternative: one .cshtml + PageModel
    AreasGroup features (Admin, Shop) into sub-sections
    Layout / PartialShared page shell / reusable fragment

    🧪 Basic · Model, Controller, View

    csharppublic class Book { public int Id { get; set; } public string Title { get; set; } = ""; }

public class BooksController : Controller
{
    public IActionResult Index() => View(_db.Books.ToList());   // sends model to view
}

    🛠️ Intermediate · ViewModels, forms, validation

    Use a ViewModel shaped for the screen, Tag Helpers for forms and Data Annotations for validation. Follow Post-Redirect-Get after saving.

    csharppublic class BookVm { [Required, StringLength(120)] public string Title { get; set; } = ""; }

[HttpPost, ValidateAntiForgeryToken]

{
    if (!ModelState.IsValid) return View(vm);      // redisplay with errors
    await _svc.AddAsync(vm);
    TempData["ok"] = "Book saved";
    return RedirectToAction(nameof(Index));        // PRG pattern
}

  <button type="submit">Save</button>
</form>
    • Partial views & View Components for reusable UI.
    • _Layout.cshtml and _ViewImports for shared markup and tag helpers.

    🚀 Expert · Filters, security, performance

    • Filter pipeline: Authorization → Resource → Action → Exception → Result filters.
    • Custom model binders and view components with async logic.
    • Security: anti-forgery tokens, output encoding (XSS), CSP headers, ASP.NET Core Identity, secure cookies.
    • Performance: response caching, AsNoTracking, bundling, async everywhere, pre-compiled views.
    • Maintainability: thin controllers, services/handlers, Areas, integration tests with WebApplicationFactory.

    Module 04 · Minimal APIs

    Minimal APIs

    Fast, low-ceremony HTTP endpoints: from a one-line hello to organised, AOT-ready services.

    ⚡ Basic · What are Minimal APIs?

    Minimal APIs map HTTP requests straight to C# lambdas or methods, with no controllers or attributes. They have less ceremony, start fast and are ideal for microservices.

    csharpvar app = WebApplication.CreateBuilder(args).Build();
app.MapGet("/", () => "Hello .NET");
app.Run();

    🗂️ Basic · Types of handlers & binding

    Parameter sourceExample
    Route/books/{id} → int id
    Query string(string? q)
    Body (JSON)(CreateBookDto dto)
    Header / Form[FromHeader], [FromForm]
    ServicesInjected automatically, e.g. IBookService svc

    Results: Results.Ok(), Created(), NotFound(), BadRequest(), Problem(); prefer TypedResults for strongly-typed responses and better OpenAPI metadata.

    🧪 Basic · CRUD example

    csharpvar books = new List<Book>();

app.MapGet("/books", () => books);
app.MapGet("/books/{id:int}", (int id) =>
    books.FirstOrDefault(b => b.Id == id) is { } b ? Results.Ok(b) : Results.NotFound());
app.MapPost("/books", (Book b) => { books.Add(b); return Results.Created($"/books/{b.Id}", b); });
app.MapDelete("/books/{id:int}", (int id) => { books.RemoveAll(b => b.Id == id); return Results.NoContent(); });

    🛠️ Intermediate · Groups, DI, filters, validation

    csharpvar api = app.MapGroup("/api/books").WithTags("Books").RequireAuthorization();

api.MapGet("/", async (IBookService svc, CancellationToken ct) => TypedResults.Ok(await svc.GetAllAsync(ct)));
api.MapPost("/", async (CreateBookDto dto, IBookService svc) =>
    TypedResults.Created("/api/books", await svc.CreateAsync(dto)))
   .AddEndpointFilter(async (ctx, next) =>
   {
       var dto = ctx.GetArgument<CreateBookDto>(0);
       return string.IsNullOrWhiteSpace(dto.Title)
           ? Results.ValidationProblem(new() { ["Title"] = ["Title is required"] })
           : await next(ctx);
   });
    • MapGroup shares prefix, auth, filters and metadata.
    • Endpoint filters are the Minimal API equivalent of action filters.

    🚀 Expert · Organising, OpenAPI, AOT

    csharp// Keep Program.cs small: one extension method per feature
public static class BookEndpoints
{
    public static RouteGroupBuilder MapBooks(this IEndpointRouteBuilder app)
    {
        var g = app.MapGroup("/api/books");
        g.MapGet("/{id:int}", GetById);
        return g;
    }
    static async Task<Results<Ok<BookDto>, NotFound>> GetById(int id, IBookService s) =>
        await s.GetAsync(id) is { } b ? TypedResults.Ok(b) : TypedResults.NotFound();
}
app.MapBooks();
    • OpenAPI metadata with WithName, Produces, WithOpenApi; use the built-in OpenAPI document support on recent .NET.
    • Native AOT (CreateSlimBuilder) for tiny, fast-starting containers; use source-generated JSON.
    • Rate limiting, caching, auth and health checks work exactly as in Web API.
    • Patterns: vertical slices, REPR pattern, CQRS with handlers.
    ✅
    Rule of thumb: Minimal APIs are not "less capable", just less structured. As the project grows, structure it with groups and extension methods.

    Module 05 · Blazor

    Blazor

    Build interactive UIs in C#: render modes, components, forms, state, JS interop and optimisation.

    🧩 Basic · What is Blazor?

    Blazor builds interactive web UIs with C# and Razor components (.razor files) instead of JavaScript. A component mixes HTML markup with C# logic and can be reused like a tag.

    🗂️ Basic · Types: render modes

    ModeWhere C# runsProsCons
    Static SSRServer, HTML onlyFast, SEO-friendlyNo interactivity
    Interactive ServerServer via SignalRSmall download, full .NET accessNeeds live connection, latency
    Interactive WebAssemblyBrowser (WASM)Offline-capable, no server loadLarger first download
    Interactive AutoServer first, then WASMFast start, then client-sideMore complex
    Blazor HybridNative app (MAUI)Reuse components in desktop/mobileNative shell required
    💡
    In .NET 8+ a single Blazor Web App template lets you choose the render mode per page or component, e.g. @rendermode InteractiveServer.

    • Cascading values pass data down the tree without parameters.
    • Routing: @page "/books/{Id:int}", NavigationManager.

    🚀 Expert · State, interop, performance, security

    • State management: scoped services with change events, PersistentComponentState, browser storage, Fluxor.
    • JS interop: IJSRuntime to call JavaScript libraries; [JSInvokable] to call C# from JS.
    • Performance: @key, ShouldRender, <Virtualize>, streaming rendering ([StreamRendering]), AOT and trimming for WASM.
    • Security: AuthorizeView, [Authorize], AuthenticationStateProvider; in Server mode, handle circuit disconnects.
    • Testing: bUnit for components, Playwright for end-to-end.

    Module 06 · Interview Preparation

    Interview Preparation

    Click a question to reveal a model answer.

    🔌 Web API

    Difference between IActionResult and ActionResult<T>?
    IActionResult returns any result without type information. ActionResult<T> carries the body type (good for OpenAPI) and still allows error results like NotFound().
    What does [ApiController] do?
    Enables automatic model-validation 400s, binding-source inference, ProblemDetails responses and requires attribute routing.
    PUT vs PATCH?
    PUT replaces the whole resource and is idempotent; PATCH applies a partial change.
    How do you secure a Web API?
    HTTPS, JWT/OAuth2 authentication, policy-based authorization, validation, rate limiting, CORS restrictions and secrets in a vault.
    How do you handle errors globally?
    IExceptionHandler or exception middleware returning ProblemDetails, plus structured logging with a correlation ID.

    🧱 MVC

    Explain the MVC request flow.
    Routing selects a controller action, model binding fills parameters, the action uses the model/services, and returns a ViewResult rendered by Razor into HTML.
    MVC vs Razor Pages?
    MVC separates controllers and views across folders; Razor Pages groups the view and its handler per page, simpler for page-centric apps.
    What are the filter types?
    Authorization, Resource, Action, Exception and Result filters, run in that pipeline order.
    What is Post-Redirect-Get?
    After a POST, redirect to a GET so a browser refresh does not resubmit the form.

    ⚡ Minimal APIs

    When choose Minimal APIs over controllers?
    Small services, microservices and performance-sensitive endpoints; use groups and extension methods to stay organised as they grow.
    How do you add validation?
    Endpoint filters, or libraries such as FluentValidation, returning Results.ValidationProblem.
    What is MapGroup?
    Groups endpoints under a common prefix and shares metadata, filters and authorization.
    What is Native AOT?
    Ahead-of-time compilation to a native binary for faster startup and lower memory; requires trimming-safe code such as source-generated JSON.

    🧩 Blazor

    Blazor Server vs WebAssembly?
    Server runs C# on the server via SignalR (small download, latency-sensitive); WebAssembly runs in the browser (offline, heavier first load).
    What are Blazor render modes?
    Static SSR, Interactive Server, Interactive WebAssembly and Auto, selectable per component or page in .NET 8+.
    How do components communicate?
    Parameters down, EventCallback up, cascading values, and shared scoped services for state.
    How do you call JavaScript?
    Inject IJSRuntime and call InvokeAsync; expose C# with [JSInvokable] and DotNetObjectReference.

    📚 Scenario: BookShelf Library Platform

    BookShelf needs (1) a JSON backend for a mobile app, (2) a public catalogue site that Google must index, (3) a tiny health/stock microservice and (4) an interactive staff dashboard — all in C#.

    • A Blazor WebAssembly
    • B ASP.NET Core Web API
    • C MVC views
    • D Razor class library
    Q. The public catalogue must be SEO-friendly. Best fit?
    • A MVC / Razor Pages with server rendering
    • B Interactive WebAssembly only
    • C Minimal API returning JSON
    • D Console app
    Q. The tiny microservice should start fast with minimal code.
    • A MVC
    • B Minimal APIs
    • C Blazor Server

    ✍️ Which framework would you use for the staff dashboard and which render mode? Justify.
    Model answer: Blazor Web App. Interactive Server suits an internal dashboard: small download, direct access to services and database, users are on a reliable network. Use Auto/WebAssembly only if offline use is needed.

    2️⃣ Task 2 · Write an endpoint

    ✍️ Write a Minimal API GET /books/{id} that returns 404 when not found.
    Model answer:

    await s.GetAsync(id) is { } b ? Results.Ok(b) : Results.NotFound());
    Q. Which return type gives a typed body and allows NotFound() in a controller?
    • A void
    • B string
    • C ActionResult<Book>
    • D object

    3️⃣ Task 3 · Fix the bug

    A teammate stores the logged-in user's name in a static string in a Blazor Server app. Users start seeing each other's names.

    ✍️ Explain the cause and the fix.
    Model answer: Static fields are shared by all users and circuits on the server. Store per-user state in a scoped service (one per circuit) or use AuthenticationStateProvider/claims.

    4️⃣ Task 4 · Secure and scale

    ✍️ List 5 steps to make the mobile API production-ready.
    Model answer: 1) HTTPS + JWT auth with policies. 2) Validation and ProblemDetails global errors. 3) Pagination and AsNoTracking queries. 4) Rate limiting and caching. 5) Health checks, structured logging and OpenTelemetry, plus integration tests with WebApplicationFactory.
