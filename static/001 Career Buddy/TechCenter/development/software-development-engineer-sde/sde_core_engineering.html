    What is Core Engineering?

    Start from zero: what a programming language is, the types of languages, and how to choose among C++, Java, Go and Python.

    🧭 What is Core Engineering?

    Core engineering is the craft of turning a problem into correct, efficient, readable and maintainable code. It combines a language, data structures & algorithms, design principles and debugging skill.

    🔴 Coder

    Makes it work once; hard to read, test or change.

    🟢 Engineer

    Makes it correct, clear, tested, fast enough and easy for others to change.

    🧪 Worked Example: Two Sum

    Problem: find two numbers that add up to a target. Brute force is O(n²); a hash map makes it O(n).

    pythondef two_sum(nums, target):
    seen = {}                      # value -> index
    for i, n in enumerate(nums):
        need = target - n
        if need in seen:
            return [seen[need], i]
        seen[n] = i
    return []

print(two_sum([2, 7, 11, 15], 9))  # [0, 1]
    ✅
    Trade memory for time: O(n) extra space bought us O(n) time instead of O(n²).

    Module 04 · Design

    OOP, SOLID & Design Patterns

    Structure code so it stays easy to change.

    🏗️ SOLID Principles

    1️⃣
    Single responsibility
    A class has one reason to change.
    2️⃣
    Open/closed
    Extend behaviour without editing old code.
    3️⃣
    Liskov substitution
    Subtypes must work wherever the parent does.
    4️⃣
    Interface segregation
    Small, focused interfaces.
    5️⃣
    Dependency inversion
    Depend on abstractions, not concretions.

    🧩 Pattern Types

    CategoryPatternsPurpose
    CreationalFactory, Builder, SingletonHow objects are created
    StructuralAdapter, Decorator, FacadeHow objects are composed
    BehaviouralStrategy, Observer, CommandHow objects interact
    pythonclass PaymentStrategy:               # Strategy pattern
    def pay(self, amt): raise NotImplementedError
class Card(PaymentStrategy):
    def pay(self, amt): return f"card {amt}"
class Upi(PaymentStrategy):
    def pay(self, amt): return f"upi {amt}"

def checkout(strategy: PaymentStrategy, amt):
    return strategy.pay(amt)         # swap behaviour, no if/else

    🧹 Clean Code Habits

    • Name things by intent; keep functions short and single-purpose.
    • Prefer composition over inheritance.
    • Handle errors explicitly; never swallow exceptions.
    • Write tests first for tricky logic; refactor with tests green.

    Interview Preparation

    🎤 Core Questions

    Stack vs heap?
    Stack: automatic, fast, scoped to function calls. Heap: dynamic, manually or GC-managed, lives until freed.
    HashMap vs TreeMap?
    Hash map O(1) average, unordered. Tree map O(log n), keeps keys sorted and supports range queries.
    What is a goroutine?
    A lightweight, runtime-scheduled thread of execution with a small growable stack; communicate via channels.
    Why the Python GIL?
    It protects interpreter memory management, so only one thread runs bytecode at a time; use processes for CPU-bound work.
    Explain RAII.
    Tie a resource's lifetime to an object's scope so cleanup runs automatically in the destructor.
    How do you find a performance bottleneck?
    Reproduce, profile, locate the hot path, fix the algorithm first, re-measure.

    🛠️ Scenario

    Design an LRU cache with O(1) get and put, capacity N.

    ✍️ Which two structures combine to achieve O(1) for both operations?
    Model answer: A hash map (key → node) plus a doubly linked list ordered by recency; move a node to the front on access, evict from the tail.
    ✍️ How would you make it thread-safe in your chosen language?
    Model answer: Guard with a mutex (or sharded locks for throughput); Java: ReentrantLock, Go: sync.Mutex, Python: threading.Lock.
