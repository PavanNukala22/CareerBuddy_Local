    Core Languages: What, Why & Types

    What a programming language is, how languages are classified, and how to choose between Python, Java, C++ and C#.

    🧭 What is a Programming Language?

    A programming language is a formal notation for giving instructions to a computer. A compiler or interpreter turns your source code into something the machine can run. Every language offers variables, control flow, functions and data structures; they differ in how they manage memory, check types and organise code.

    Source codeHuman-readable text you write.
    CompilerTranslates the whole program ahead of time (C++, Java to bytecode, C# to IL).
    InterpreterRuns code line by line at runtime (Python).
    Runtime / VMEnvironment that executes bytecode: JVM (Java), CLR (C#), CPython (Python).
    ParadigmA style of programming: procedural, object-oriented, functional.

    🗂️ Types of Languages

    By execution
    Compiled (C++), bytecode + VM (Java, C#), interpreted (Python).
    By typing
    Static (Java, C++, C#) vs dynamic (Python); strong vs weak.
    By paradigm
    Procedural, object-oriented, functional, generic. All four languages are multi-paradigm.
    By memory
    Manual (C++), garbage-collected (Java, C#, Python).

    ⚖️ Python vs Java vs C++ vs C#

    Runs onCPythonJVMNative.NET CLR

    Python: Basic to Expert

    Readable, dynamically typed and versatile.

    🐍 What is Python?

    Python is a high-level, interpreted, dynamically typed language that values readability. Blocks are defined by indentation. Core types: int, float, str, bool, list, tuple, dict, set.

    pythonname = "Asha"; age = 21          # variables, no type declaration

user = {"id": 1, "name": name}   # dict
for n in nums:
    if n % 2: print(n, "odd")
    else:     print(n, "even")

    🧱 Functions, Comprehensions & OOP

    pythondef area(w, h=1): return w * h
squares = [x*x for x in range(10) if x % 2 == 0]

class Account:
    def __init__(self, owner, bal=0):
        self.owner, self._bal = owner, bal
    def deposit(self, amt):
        if amt <= 0: raise ValueError("amount must be > 0")
        self._bal += amt
        return self._bal
    Example

    Account('Ravi').deposit(500) returns 500; a negative amount raises ValueError.

    Module 03 · Java

    Java: Basic to Expert

    Statically typed, object-oriented, write once run anywhere.

    ☕ What is Java?

    Java compiles to bytecode that runs on the JVM. Types are either primitives (int, double, boolean, char…) or reference types (classes, arrays, interfaces). The JVM garbage-collects unused objects.

    javapublic class Main {
    public static void main(String[] args) {
        int[] nums = {1, 2, 3};
        int sum = 0;
        for (int n : nums) sum += n;
        System.out.println("Sum = " + sum);
    }
}

    Module 04 · C++

    C++: Basic to Expert

    Fast, close to the hardware, with manual control over memory.

    ⚙️ What is C++?

    C++ is a compiled, statically typed, multi-paradigm language. Code is compiled to native machine code, so it is fast but you manage memory yourself. Core types: int, double, char, bool, plus std::string and std::vector.

    cpp#include <iostream>
#include <vector>
int main() {
    std::vector<int> v{3, 1, 2};
    int sum = 0;
    for (int x : v) sum += x;
    std::cout << "Sum = " << sum << "
";
}

    📍 Pointers, References & Classes

    cppint a = 10;

    ⚠️
    A dangling pointer or a missing delete causes crashes and leaks. Prefer smart pointers.

    C#: Basic to Expert

    🔷 What is C#?

    C# compiles to IL that runs on the .NET CLR, with garbage collection. It is used for web APIs (ASP.NET Core), desktop apps and Unity games. Types are value types (int, struct) or reference types (class, string).

    Module 06 · Practice

    Practice: Core Language Exercises

    Attempt each task in your preferred language, then compare with the model answer.

    🧪 Exercises

    Q1Write a function that returns whether a string is a palindrome (ignore case).

    Python: def is_pal(s): s=s.lower(); return s==s[::-1]. Java/C#: compare characters from both ends with two indexes. C++: use std::equal(s.begin(), s.begin()+s.size()/2, s.rbegin()).

    Q2Count word frequencies in a sentence.

    Python: collections.Counter(text.split()). Java: Map<String,Integer> with merge(w,1,Integer::sum). C#: GroupBy(w=>w).ToDictionary(g=>g.Key,g=>g.Count()). C++: std::map<string,int> and ++m[w].

    Q3Design a BankAccount class that rejects overdrafts. Which OOP principle protects the balance?

    Keep the balance private and change it only via deposit and withdraw, which validate input and throw an exception on overdraft. This is encapsulation.

    Q4Explain why a C++ unique_ptr is safer than raw new/delete.

    It frees the object automatically when it goes out of scope (RAII), even if an exception occurs, so there are no leaks or double deletes, and ownership is explicit.
