    Module 01 · Basics

    What is Styling & Why So Many Tools?

    From plain CSS to utility classes and CSS-in-JS.

    🧭 What is what?

    Styling tools help you write, organise and scale CSS. Plain CSS gets hard to maintain in big apps because styles are global — one class name can clash with another.

    ApproachIdeaExamples
    Utility-firstCompose small single-purpose classes in HTMLTailwind CSS
    PreprocessorCSS with variables, nesting, mixins compiled to CSSSass / SCSS
    Scoped filesClass names auto-made unique per fileCSS Modules
    CSS-in-JSWrite styles in JavaScript, tied to componentsstyled-components, Emotion

    📏 CSS foundations you need first

    • Specificity: inline > id > class > element.
    • Cascade & inheritance; use rem for text, %/fr for layout.
    • Naming: BEM — .card__title--large.
    css.card__title--large { font-size: 2rem; }

    Tailwind CSS: Utility-First

    Build designs directly in markup with utilities, variants and a config.

    🌬️ Utilities & variants

    html<button class="px-4 py-2 rounded-lg bg-slate-900 text-white
               hover:bg-slate-700 focus:ring-2 md:px-6 dark:bg-white dark:text-black">
  Save

    Spacingp-4 = 1rem; scale of 4px steps.
    Responsivesm: md: lg: are min-width breakpoints (mobile-first).
    Statehover: focus: disabled: group-hover:
    Dark modedark: variant.

    ⚙️ Customising

    Module 03 · Sass & CSS Modules

    Sass (SCSS) and CSS Modules

    Variables, nesting, mixins, and locally scoped class names.

    💅 Sass / SCSS

    scss$brand: #14213D;
@mixin respond($bp) { @media (min-width: $bp) { @content; } }
.card {
  color: $brand;
  &:hover { opacity: .9; }
  .title { font-weight: 600; }
  @include respond(768px) { padding: 2rem; }
}
@use "sass:math";

    Use @use / @forward (not @import). Features: variables, nesting, mixins, functions, partials.

    📦 CSS Modules

    jsximport styles from "./Button.module.css";
export const Button = () => <button className={styles.primary}>Go</button>;
// Compiles to: class="Button_primary__x7a2d" — no clashes!

    Best for teams wanting plain CSS with automatic scoping and zero runtime cost.

    Advanced→ Expert
    Module 04 · CSS-in-JS & Expert

    CSS-in-JS, Design Tokens & Architecture

    Dynamic styling, theming, performance trade-offs and scaling styles.

    💄 styled-components / Emotion

    jsxconst Btn = styled.button`
  background: ${p => (p.$primary ? "#14213D" : "#eee")};
  &:hover { opacity: .9; }
`;
<Btn $primary>Save</Btn>
    ⚠️
    Runtime CSS-in-JS adds JS cost and struggles with Server Components. Prefer zero-runtime options (Tailwind, CSS Modules, vanilla-extract, Panda CSS) in new projects.

    🎛️ Design tokens & theming

    css:root { --color-bg: #fff; --space-2: .5rem; --radius: 8px; }
[data-theme="dark"] { --color-bg: #111; }
.card { background: var(--color-bg); padding: var(--space-2); border-radius: var(--radius); }

    Tokens are the single source of truth for colour, spacing and type — shared by design and code.

    🏛️ Choosing & scaling

    NeedPick
    Fast UI, consistent designTailwind CSS
    Familiar CSS, scopedCSS Modules
    Legacy / big design systemSass
    Highly dynamic themesCSS variables + zero-runtime CSS-in-JS
