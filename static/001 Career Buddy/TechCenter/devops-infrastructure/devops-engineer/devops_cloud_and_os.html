    Module 01 · Foundations

    Cloud Computing Fundamentals

    The cloud rents you computing on demand. AWS, Azure and GCP offer the same building blocks under different names, so learning one makes the others easy.

    ☁️ What is cloud computing? Basic

    Instead of buying servers, you use someone else's data centres and pay for what you use, through an API or console, in minutes.

    🔌
    Analogy: electricity. You do not build a power plant; you plug in and get a bill by usage.
    ⚡
    On-demand
    Create and delete resources in minutes
    📏
    Elastic
    Scale up for peaks, down afterwards
    💳
    Pay-as-you-go
    Operating expense instead of hardware purchase
    🌍
    Global
    Regions and zones close to users

    🤝 Shared responsibility and global structure Intermediate

    • Region: a geographic area; Availability Zone: isolated data centre(s) inside a region. Spread workloads over at least two zones.
    • Shared responsibility: the provider secures the cloud (hardware, facilities); you secure what you put in it (identity, data, configuration).
    ⚠️
    Most cloud breaches are customer misconfigurations: public buckets, over-broad IAM, exposed keys.

    👤 Users and permissions Basic

    Permissions are three triplets: owner, group, others, each with read (4), write (2), execute (1).

    bashls -l app.sh        # -rwxr-x--- 1 deploy ops ...
chmod 750 app.sh    # owner rwx, group r-x, others none
chown deploy:ops app.sh
useradd -m -s /bin/bash alice
usermod -aG docker alice
visudo              # grant sudo safely
    📌
    Special bits: setuid, setgid, sticky bit (/tmp). Prefer ACLs (setfacl) for complex sharing.

    🧠 Expert: performance, security, boot Expert

    • USE method: for CPU, memory, disk, network check Utilisation, Saturation, Errors.
    • Tools: vmstat 1, iostat -x 1, sar, pidstat, strace -p, perf, bpftrace.
    • Memory: free vs available, page cache, swap, OOM-killer logs in dmesg.
    • Hardening: SSH keys only, PermitRootLogin no, firewall default-deny, SELinux/AppArmor enforcing, unattended security updates, auditd.
    • Kernel tuning: sysctl, ulimit, cgroups limits.
    bash# Quick triage when a server is slow
uptime                       # load average
vmstat 1 5                   # cpu, run queue, swap
iostat -x 1 3                # disk saturation
ss -s                        # socket counts
dmesg -T | tail -30          # OOM kills, disk errors
journalctl -p err -b         # errors since boot

    Bash Scripting

    Bash glues commands together. It is perfect for short automation and CI steps, and risky when scripts grow large.

    🐚 Basics Basic

    Variables, conditions, loops:

    bash#!/usr/bin/env bash
name="web"
count=3

if [ "$count" -gt 2 ]; then
  echo "$name has many replicas"
fi

for host in web1 web2 web3; do
  ping -c1 -W1 "$host" >/dev/null && echo "$host up" || echo "$host DOWN"
done
    ⚠️
    Always quote variables: "$var". Unquoted values break on spaces and glob characters.

    🛡️ Expert: safe, reliable scripts Expert

    Start every serious script with strict mode, cleanup and logging:

    bash#!/usr/bin/env bash
set -Eeuo pipefail                 # stop on error, unset var, pipe failure
IFS=$'\n\t'

tmp=$(mktemp -d)
cleanup() { rm -rf "$tmp"; }
trap cleanup EXIT                  # always runs
trap 'echo "failed at line $LINENO" >&2' ERR

log() { printf '%s %s\n' "$(date -Iseconds)" "$*"; }

while getopts "e:d" opt; do
  case $opt in
    e) env=$OPTARG ;;
    d) dry=1 ;;
    *) exit 2 ;;
  esac
done
log "deploying to ${env:?-e env required}"
    💡
    Lint with ShellCheck, test with bats. If your script needs complex data structures or error handling, move to Python.

    ☁️ Cloud automation with boto3 Intermediate

    Find and stop untagged dev instances to save money:

    pythonimport boto3

ec2 = boto3.client("ec2", region_name="eu-west-1")
resp = ec2.describe_instances(
    Filters=[{"Name": "instance-state-name", "Values": ["running"]}])

to_stop = []
for r in resp["Reservations"]:
    for i in r["Instances"]:
        tags = {t["Key"]: t["Value"] for t in i.get("Tags", [])}
        if tags.get("env") == "dev":
            to_stop.append(i["InstanceId"])

if to_stop:
    ec2.stop_instances(InstanceIds=to_stop)
    print("Stopped:", to_stop)
    📌
    Credentials come from the environment, instance role or SSO profile. Never hard-code keys.

    🧠 Expert: production-grade tools Expert

    • CLI with argparse, --dry-run, structured logs, exit codes.
    • Retries with exponential backoff and jitter, timeouts on every call, pagination.
    • Idempotent actions and safety limits (maximum items changed per run).
    • Package with pyproject.toml, type hints, tests (pytest, moto to mock AWS).
    pythonimport argparse, logging

p = argparse.ArgumentParser()
p.add_argument("--env", required=True)
p.add_argument("--dry-run", action="store_true")
args = p.parse_args()

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
log = logging.getLogger("cleanup")

def stop(ids):
    if args.dry_run:
        log.info("[dry-run] would stop %s", ids); return
    ec2.stop_instances(InstanceIds=ids)
