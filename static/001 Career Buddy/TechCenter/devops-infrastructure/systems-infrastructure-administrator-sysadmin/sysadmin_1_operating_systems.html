    OS Fundamentals

    What an operating system does, the families you will administer, and how a server boots.

    🧠 What is an Operating System?

    An OS is the software layer between hardware and applications. The kernel manages CPU, memory, devices and processes; user space holds shells, services and tools; the init system starts everything at boot.

    ⚙️
    Kernel
    Schedules processes, manages memory, drivers.
    🖥️
    Shell
    CLI to talk to the OS: bash, PowerShell.
    🔧
    Services
    Background daemons: sshd, nginx, W32Time.
    📁
    Filesystem
    ext4/XFS on Linux, NTFS/ReFS on Windows.

    🧬 OS Families & Types

    OSFamilyPackage toolTypical use
    RHEL (Rocky, Alma)Red Hatdnf/rpmEnterprise, long support, SELinux

    💡
    Rule of thumb: pick RHEL-family for vendor-supported apps, Debian/Ubuntu for flexibility, Windows Server when Active Directory or .NET is central.

    🚀 Boot Process

    Firmware (BIOS/UEFI) → bootloader (GRUB / Windows Boot Manager) → kernel + initramfs → init (systemd) → targets/services → login.

    cat /etc/os-release     # which distro and version
uname -r                # kernel version
systemctl get-default   # multi-user.target = no GUI
systemd-analyze blame   # what slowed the boot

    Linux Administration

    Users, permissions, packages, services, storage and logs — from first commands to LVM.

    👤 Users & Permissions

    Basic

    sudo useradd -m -s /bin/bash alice
sudo passwd alice
sudo usermod -aG wheel alice   # sudo group (RHEL: wheel, Debian: sudo)
chmod 640 report.txt           # rw- r-- ---
chown alice:devs report.txt

    Intermediate

    Permissions are 3 sets (user/group/other) of r=4, w=2, x=1. Special bits: setuid, setgid, sticky (/tmp). Use visudo for sudoers and setfacl for per-user ACLs.

    setfacl -m u:bob:rw /srv/data/plan.txt   # extra user without changing group
    🧪
    Expert: authentication flows through PAM (/etc/pam.d); enforce password policy with pam_pwquality and lockout with pam_faillock.

    📦 Packages & Services

    TaskRHEL / RockyDebian / Ubuntu
    Installdnf install nginxapt install nginx
    Update alldnf upgradeapt update && apt upgrade

    Add repo/etc/yum.repos.d//etc/apt/sources.list.d/
    systemctl enable --now nginx

journalctl -u nginx -f --since "1 hour ago"
    🛠️
    Write your own unit in /etc/systemd/system/app.service with Restart=on-failure, then systemctl daemon-reload.

    💽 Storage: Partitions, LVM, RAID

    LVM stacks PV → VG → LV so volumes can grow online. RAID (mdadm) adds redundancy: RAID1 mirror, RAID5 parity, RAID10 mirror+stripe.

    pvcreate /dev/sdb
vgcreate data_vg /dev/sdb
lvcreate -L 50G -n app_lv data_vg
mkfs.xfs /dev/data_vg/app_lv
lvextend -r -L +20G /dev/data_vg/app_lv   # grow LV + filesystem online
    ⚠️
    Always check lsblk and df -h before formatting. Use UUIDs in /etc/fstab and test with mount -a.

    Windows Server

    Roles, PowerShell administration, Server Core and Group Policy.

    🪟 Roles, Features & Editions

    🏢
    AD DS
    Domain identity and authentication.
    🌐
    DNS / DHCP
    Name resolution and IP leasing.
    📂
    File Services
    SMB shares, DFS, quotas, dedup.
    🧱
    Hyper-V
    Built-in hypervisor for VMs.

    Standard allows 2 VMs per licence; Datacenter unlimited. Server Core has no GUI: smaller attack surface and fewer patches.

    ⌨️ PowerShell Administration

    Install-WindowsFeature AD-Domain-Services,DNS -IncludeManagementTools
Get-Service | Where Status -eq Stopped
New-LocalUser "svc_app" -Password (Read-Host -AsSecureString)
Get-WinEvent -LogName System -MaxEvents 20
Get-HotFix | Sort InstalledOn -Desc | Select -First 5
    💡
    Remote admin: Enter-PSSession -ComputerName SRV01 (WinRM). Expert level: use Desired State Configuration or Ansible to keep servers identical.

    📜 Group Policy & Permissions

    GPOs apply settings to users/computers by OU in order Local → Site → Domain → OU (LSDOU); the last one wins. Share permissions combine with NTFS permissions — the most restrictive applies.

    gpupdate /force
gpresult /r        # which GPOs applied to this machine/user

    Hardening & Tuning

    Expert-level security baselines, performance analysis and structured troubleshooting.

    🛡️ Linux Hardening

    • SELinux (RHEL) / AppArmor (Ubuntu): mandatory access control — never just disable it; read ausearch -m avc.
    • Disable root SSH login and passwords; use keys.
    • Firewall: firewalld or ufw, default deny.
    • Auditing with auditd; benchmark against CIS or run oscap.
    getenforce
firewall-cmd --permanent --add-service=https && firewall-cmd --reload
ufw default deny incoming && ufw allow 22/tcp

    📈 Performance Analysis

    SymptomToolLook at
    High loadtop/htopCPU %, load average vs core count
    Swappingvmstat 1si/so columns
    Slow diskiostat -x 1%util, await
    Networkss -tulpn, sar -n DEVListening ports, throughput
    sysctl -w vm.swappiness=10   # persist in /etc/sysctl.d/

    🔍 Troubleshooting Method

    1) Define the symptom → 2) check recent changes → 3) read logs → 4) form one hypothesis → 5) test → 6) document. Windows: Event Viewer, perfmon, sfc /scannow.

    ✅
    Always keep a rollback: snapshot the VM or copy the config before changing it.
