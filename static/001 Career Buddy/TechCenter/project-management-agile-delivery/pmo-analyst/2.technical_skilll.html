    Module 01

    PMO Analyst Technical Skills: Foundations

    Why six tools matter and how they connect.

    🧠 Course Overview: What the Role Needs

    A PMO Analyst turns raw project data into trusted, readable, shareable information. This course covers the six tools behind that work.

    💡
    Tools are a means: pick the right one for the question, the audience and the data size.

    🎯 Learning Objectives

    By the end of this course you will be able to:

    1. Build analysis and trackers in Advanced Excel with lookups, pivots and Power Query.
    2. Model data and publish dashboards in Power BI with DAX measures.
    3. Design clear, fast visuals in Tableau.
    4. Write JQL and build Jira dashboards for delivery reporting.
    5. Structure a Confluence space as a PMO intranet.
    6. Organise SharePoint sites, libraries, metadata and permissions.

    Module 02

    Advanced Excel

    Lookups, pivots, Power Query and tracker design.

    📊 Basic: Formulas that Matter

    TaskUseExample
    Conditional totalSUMIFS=SUMIFS(Cost,Project,A2,Month,B2)
    LookupXLOOKUP=XLOOKUP(A2,IDs,Owners,"None")
    Count with rulesCOUNTIFS=COUNTIFS(Status,"Late")
    Clean textTRIM, TEXT=TRIM(A2)
    💡
    Keep inputs on one sheet, calculations on another, and use Excel Tables so formulas expand automatically.

    🔄 Intermediate: PivotTables and Power Query

    • PivotTable: summarise by project, month or owner; add slicers for filtering.
    • Power Query: import, clean and merge files; steps are recorded and refresh with one click.
    • Data validation: dropdowns stop invalid entries at source.
    formula// Variance % = (Actual - Budget) / Budget
=(C2-B2)/B2

    ⚙️ Advanced: Models, Dashboards and Controls

    • Use the Data Model to relate tables and build pivots across them.
    • Dynamic arrays (FILTER, UNIQUE, SORT) build live lists without copying formulas.
    • Add conditional-formatting RAG status; lock formula cells and protect sheets.
    • Document assumptions and keep a version label on every file.
    ⚠️
    Hard-coded numbers inside formulas hide errors. Put assumptions in labelled cells.

    Module 03

    Power BI

    Data modelling, DAX measures and published reports.

    📈 Basic: Desktop, Service and Basic Visuals

    • Power BI Desktop builds the model and report; the Service shares it.
    • Pick visuals by question: card (one number), bar (compare), line (trend), table (detail).
    • Use slicers and filters; keep one message per page.

    🧮 Intermediate: Star Schema and DAX

    Fact table

    • Transactions: cost, hours, dates
    • Many rows
    • Holds keys to dimensions

    Dimension tables

    • Project, Owner, Date
    • Fewer rows
    • Descriptive attributes
    DAXBudget Variance =
SUM(Actuals[Amount]) - SUM(Budget[Amount])

Late Projects =
CALCULATE(COUNTROWS(Projects), Projects[Status] = "Late")

    🔐 Advanced: Publishing, Refresh and Security

    • Workspaces and apps distribute reports to the right audience.
    • Schedule refresh; an on-premises gateway is needed for on-premises sources.
    • Row-level security limits rows by user role, e.g. a manager sees only their portfolio.
    • DirectQuery queries the source live; Import loads a copy for speed.
    ⚠️
    Never rely on hiding a page for security. Use row-level security and workspace roles.

    Module 04

    Tableau

    Visual analytics, calculations and dashboard design.

    🎨 Basic: Dimensions, Measures and Charts

    Field typeExamplesBehaviour
    Dimension (blue)Project, Owner, MonthSplits the view
    Measure (green)Cost, HoursAggregated numbers
    • Drag fields to Rows and Columns; use Marks for colour, size and labels.

    🧪 Intermediate: Calculations and Extracts

    • Calculated fields add logic, e.g. IF [Status]="Late" THEN 1 ELSE 0 END.
    • Live connections query the source; extracts (.hyper) are fast snapshots.
    • Parameters let viewers choose a measure or date.
    tableau// Total budget per project, fixed regardless of view
{ FIXED [Project] : SUM([Budget]) }

    🚀 Advanced: Dashboards and Governance

    • Use filter and highlight actions so charts interact.
    • Reduce marks, filters and complex calculations to speed dashboards.
    • Publish to Tableau Server or Cloud with project folders and permissions.
    💡
    Design for the viewer: title that states the message, 3–5 charts, consistent colour meaning.

    Module 05

    Jira Enterprise Reporting

    JQL, filters, dashboards and delivery metrics.

    🧾 Basic: Jira Basics for Reporting

    • Issues (epic, story, task, bug) belong to projects and move through a workflow.
    • Fields such as status, assignee, due date, labels and fix version drive reports.
    • Boards visualise work; reports summarise it.

    🔎 Intermediate: JQL, Filters and Dashboards

    JQLproject = PMO AND status != Done AND duedate < now() ORDER BY priority DESC
    • Save a JQL search as a filter; dashboard gadgets display filter results.
    • Standard reports: burndown, velocity, created vs resolved.

    📉 Advanced: Enterprise-Level Reporting

    • Use Advanced Roadmaps / Plans (Premium) to see cross-team capacity and dependencies.
    • Export to Excel or connect to Power BI for portfolio dashboards.
    • Standardise fields and workflows so data is comparable across teams.
    ⚠️
    Poor data entry means poor reports. Agree required fields and update rules first.

    Module 06

    Confluence Intranet Management

    Spaces, templates, macros and PMO knowledge hub.

    📚 Basic: Spaces, Pages and Templates

    • A space groups content for a team or project; pages form a tree.
    • Use templates for status reports, meeting notes and decision logs.
    • Use clear titles and labels to make pages searchable.

    🧩 Intermediate: Macros and Reporting

    • Jira issues macro shows live issues on a page.
    • Page Properties + Page Properties Report roll up status from many project pages into one table.
    • Table of contents macro helps long pages.

    🏛️ Advanced: Intranet Governance

    Weak

    • Everyone edits everything
    • No page owners
    • Outdated pages stay

    Strong

    • Space and page permissions by group
    • Named owner and review date
    • Archive old content
    💡
    Build a PMO home page with links to templates, reports, policies and contacts.

    Module 07

    SharePoint

    Sites, libraries, metadata, permissions and approvals.

    🌐 Basic: Sites and Document Libraries

    Site typeUse
    Team siteCollaboration for a project or team
    Communication siteBroadcast information to many readers
    • Store files in document libraries; use lists for tracking items.

    🗃️ Intermediate: Metadata, Views and Versioning

    • Add metadata columns (project, status, owner) instead of deep folders.
    • Create views to filter and group documents.
    • Versioning keeps earlier versions so you can restore them.
    • Use content types for standard document sets.

    🛡️ Advanced: Permissions, Hubs and Automation

    • Manage access with groups (Owners, Members, Visitors); avoid item-level unique permissions.
    • A hub site connects related sites with shared navigation and search.
    • Power Automate can run approval flows on documents.
    • Apply retention and sensitivity labels with IT.
    ⚠️
    Too many unique permissions make access hard to audit. Grant by group at site or library level.

    Module 09

    Interview Preparation

    Questions asked in PMO Analyst interviews. Draft your answer, then compare with the model answer.

    🎤 Interview Questions

    IQ1.Excel: XLOOKUP vs VLOOKUP?
    XLOOKUP looks left or right, defaults to exact match and has a not-found option; VLOOKUP only looks right.
    IQ2.What is a star schema and why use it in Power BI?
    Fact table linked to dimension tables; it is fast, simple and gives correct filtering.
    IQ3.Live connection vs extract in Tableau?
    Live queries the source for fresh data; extract is a faster snapshot refreshed on a schedule.
    IQ4.How do you report delivery status from Jira?
    Write JQL, save filters, build dashboard gadgets and use burndown/created-vs-resolved reports; export to Power BI for portfolio views.
    IQ5.How do you keep a Confluence intranet current?
    Owners and review dates, templates, labels, archive old pages and use Page Properties Report for roll-ups.
    IQ6.How do you secure SharePoint content?
    Use groups at site or library level, avoid unique item permissions, apply versioning and retention.
